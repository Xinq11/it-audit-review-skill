# 通用底稿复核

这是通用复核规则，不代表特定机构的方法论。先读 [来源与适用性](sources.md)。`R` 是本 skill 的复核建议；`M` 表示必须读取项目方法论或经理确认的项目规则。适用准则优先，项目规则优于本文件的一般建议；两者冲突时提交专业判断，不自行取舍。

只评价实际取得的材料。`evidence_gap` 表示目前不能支持判断；只有已见事实显示偏离适用要求，才标 `potential_control_exception`。缺陷等级不由本 skill 决定。下表输出是发现问题时的候选类型，不能看到关键词就自动报错。

| ID | 适用条件与检查动作 | 所需证据 | 输出类型 | 依据 |
|---|---|---|---|---|
| COM-001 | 每个控制：串联风险、控制目标、描述、程序、样本、证据、例外和结论；核对系统、环境、期间、责任人及频率 | 范围说明、控制矩阵、测试表、附件索引 | documentation_issue / evidence_gap | R；S1 文档原则 |
| COM-002 | 涉及有效性结论：分别判断设计是否回应风险、控制是否实施、运行测试是否支持所述期间；不把制度、单时点配置或询问单独当作全年运行证明 | 控制描述、穿行记录、配置、执行记录及运行测试 | evidence_gap / professional_judgment | S3 .42—.50；M |
| COM-003 | 使用总体及样本：追溯来源、提取条件、期间和加工；检查完整准确性、样本归属、选择理由及适用测试属性；抽样数量按 M 核对，未知则说明无法核验 | 原始总体、提取记录、核对证据、抽样依据、样本标识 | evidence_gap / documentation_issue | R；S2 .10；M |
| COM-004 | 期中测试或跨期证据：对照目标期间，检查剩余期间程序及变更说明；“期中至期末未变”需要支持，截图日期不能替代覆盖解释 | 测试日期、剩余期间程序、变更记录 | evidence_gap / professional_judgment | R；S3 .52；M |
| COM-005 | 使用报表或清单：按用途标记审计使用的企业信息及控制执行依赖的信息，两者可重叠；检查来源、筛选、字段精度、转换和完整准确性，沿依赖追到相关控制 | 报表定义、参数、源数据核对或相关控制测试 | evidence_gap | S2 .10；R；M 定义 IPE/IUC |
| COM-006 | 每个引用及图片：保留文件、页码/单元格/图片锚点；核对对象、环境、时间及可读性。抽取或视觉读取失败列未完成检查；不声称鉴定截图真实 | 原文件、提取清单、原图、交叉引用 | documentation_issue / evidence_gap | R；S1 可追溯原则 |
| COM-007 | 存在异常或互相矛盾的信息：记录事实、适用要求、追加程序及结论如何考虑；区分记录问题、证据缺口与疑似例外；影响和等级交人工 | 异常明细、回应、追加测试、评价记录 | potential_control_exception / professional_judgment | S1 .08；S3 .48；M |

写意见时使用“在已审阅材料中未见……”描述缺失；不得改写为“没有执行……”。空白、不可读、未提供与零笔发生分别处理。未发现问题只表示本次完成的检查未发现问题，不表示控制有效或正式复核已签署。

脚本输出的 `FACT-001`—`FACT-006` 是从映射表中已记录事实生成的候选意见；须核对原始证据、适用规则及例外条件后再纳入 review notes，不能自动证明客户控制失效。各检查能力与边界见 [自动检查说明](automation.md)。
